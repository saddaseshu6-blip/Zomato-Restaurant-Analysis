# Title : Zomato-Restaurant-Analysis
## Objective :
To analyze Zomato restaurant data using Excel, SQL, Power BI, and Tableau to understand restaurant distribution, customer ratings, cuisines, pricing, online delivery, and table booking trends. The project focuses on data cleaning, exploratory analysis, and interactive dashboard development to identify business insights, compare restaurant performance across countries and cities, and support better business decision-making.
